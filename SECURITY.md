# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Pipeline Sentinel, please report it privately to the maintainers.  
We appreciate your effort and will respond as quickly as possible.

- **Email:** [mehrdoost@users.noreply.github.com](mailto:mehrdoost@users.noreply.github.com)
- **PGP Key:** (optional – add your key fingerprint here)

Please do not open a public issue until the fix has been released.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.3.x   | ✅ |
| < 0.3.0 | ❌ |

## Disclosure Process

1. The vulnerability is reported privately.
2. The maintainers confirm the issue and develop a fix.
3. A new release is prepared.
4. A public advisory is published in the GitHub Security Advisories section.
